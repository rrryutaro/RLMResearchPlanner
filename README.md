# RLMResearchPlanner

日本語 | [English](README.en.md)

『ロードモバイル』の研究と建設を計画するための非公式ツールです。Windows PC版と、ブラウザーで使えるモバイル版があります。両方で同じ研究・施設データを使い、対応するJSONファイルを相互に受け渡せます。

現在の公開版`v0.1.4`はアルファ版です。主要機能を実際に利用できる段階ですが、機能・画面・収録データは引き続き検証と改善を行っています。

本ツールはIGGおよびゲーム運営とは関係ありません。ゲーム名、商標、その他の権利は各権利者に帰属します。

## 利用する

- Windows PC版は[GitHub Releases](https://github.com/rrryutaro/RLMResearchPlanner/releases)からダウンロードできます。
- [モバイル版](https://rrryutaro.github.io/RLMResearchPlanner/)はスマートフォン、タブレット、PCのブラウザーで利用できます。必要に応じてホーム画面へ追加できるPWA形式です。
- OCRによる入力補助はWindows PC版だけにあります。研究・建設計画、プレイヤー設定、データ共有などは両方で利用できます。

![モバイル版を開くQRコード](https://raw.githubusercontent.com/rrryutaro/RLMResearchPlanner/main/tools/RLMResearchPlannerPWA/docs/qr.png)

## 最初に行う設定

正しい時間を計算するため、プレイヤー設定で次の値を入力してください。

- VIPレベル
- 研究速度（研究向け装備や一時的な速度アップを含む、実際に使う状態の値）
- 建設速度（建設向け装備や一時的な速度アップを含む、実際に使う状態の値）

OCRで研究レベルを取り込む場合は、ゲーム画面とツール側で同じ研究分野を表示してから実行してください。OCR結果は誤認識することがあるため、反映後のレベルを確認してください。

初回起動時は、OSまたはブラウザーの優先言語から表示言語を選びます。対応言語が見つからない場合は英語を表示します。一度手動で選んだ言語は保存されます。

## データの共有と翻訳

- [書き出し・読み込みファイルの違い](docs/ja-JP/data-files.md)
- [翻訳ファイルの作成・読み込み方法](docs/ja-JP/translation-files.md)
- [コミュニティ翻訳の提供方法](translations/community/README.ja.md)

バックアップはプレイヤーデータ全体を置き換えます。研究指示と課金比較は、受け取り側のプレイヤーデータを維持したまま対象データを追加します。翻訳ファイルは画面表示用で、プレイヤーデータを変更しません。

## データとプライバシー

- PC版の設定とプレイヤーデータはツールと同じ場所へ保存されます。
- モバイル版のデータは利用中のブラウザー内へ保存されます。
- データはクラウドへ自動同期されません。端末変更前はバックアップを書き出してください。
- OCRは利用者が操作したときだけ画面を取得します。ゲームプロセスへのアタッチ、メモリ読み取り、ゲーム操作の自動化は行いません。

## 対応状況と注意

- OCRは入力補助機能であり、すべての環境・画面・研究項目を正しく認識できる段階ではありません。確認対象は日本語と英語です。ゲームとツールで同じ研究分野を表示し、読み取り結果を必ず確認してください。
- 動作確認済みゲームバージョンは`v2.200.309`です。これは最低動作バージョンを示すものではありません。
- 公開元で確認できない研究時間や資源は推測で補完せず、未収録として扱います。
- ギルドデュエルは研究項目の構造を収録していますが、レベル別の時間・資源・専用素材データは未収録です。
- Windows版はコード署名を行っていないため、SmartScreenの警告が表示される場合があります。
