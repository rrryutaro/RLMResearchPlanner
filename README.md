# RLMResearchPlanner

`RLMResearchPlanner`は、『ロードモバイル』の研究と建設を計画するための非公式ツールです。Windows PC版とブラウザーで動作するモバイル版があり、研究状況、計画、課金比較などのデータを共通形式で受け渡せます。

本ツールはIGGおよびゲーム運営とは関係ありません。ゲーム名、商標、その他の権利は各権利者に帰属します。

## 利用する

### Windows PC版

- 現在の公開版: `v0.0.20`
- [GitHub Releases](https://github.com/rrryutaro/RLMResearchPlanner/releases)から`RLMResearchPlanner.exe`をダウンロードしてください。
- Windows版は研究画面などのスクリーンショットを取得し、OCRで入力を補助できます。手動入力も利用できます。
- 設定とプレイヤーデータはexeと同じフォルダーへ保存されます。

WindowsのSmartScreenが未署名アプリとして警告する場合があります。Releaseに添付したSHA-256ファイルで、ダウンロードしたexeを照合できます。

### モバイル版（PWA）

PWA（Progressive Web App）は、ブラウザーから利用でき、必要に応じてスマートフォンのホーム画面へ追加できるアプリ形式です。アプリストアからのインストールは必要ありません。

- 現在の公開版: `v0.0.15`
- [RLM Research Planner モバイル版](https://rrryutaro.github.io/RLMResearchPlanner/)をスマートフォン、タブレット、PCのブラウザーから利用できます。
- ホーム画面へ追加すると、通常のアプリに近い形で起動できます。
- モバイル版はOCRを行わず、研究レベルやプレイヤー設定を手動で入力します。
- 入力内容は利用しているブラウザー内へ保存されます。

## PC版とモバイル版で共通する機能

- 研究ツリーと、目標研究までに必要な前提研究の確認
- 研究と建設に必要な時間、資源、特殊資材、パワーの集計
- 研究計画と建設計画のタスク管理
- 研究時間、建設時間、ギルドヘルプ、叡智の輪を反映した計算
- 課金パックに含まれるジェム、スピードアップ、素材などの価値比較
- 日本語・英語表示と、利用者が編集できる翻訳ファイル

Windows版とモバイル版は同じ研究・施設データを使用します。画面構成や入力方法は異なりますが、計画の計算基準とデータ形式は共通です。

## データの受け渡し

データはクラウドへ自動同期されません。ファイルへ書き出し、PC版、モバイル版、または他の利用者へ渡して読み込みます。

- **バックアップ:** プレイヤー設定、現在レベル、タスクなどをまとめて保存します。復元すると、現在のデータ全体をバックアップ内容へ置き換えます。
- **研究指示データ:** 指定した研究計画だけを渡します。受け取った側の現在レベルやプレイヤー設定は置き換えず、不足している研究だけを計算します。
- **課金比較データ:** 保存した課金項目と比較設定を渡します。プレイヤー設定を置き換えず、読み込んだ項目を追加します。
- **翻訳ファイル:** 既存の翻訳を修正したり、新しい言語の翻訳を追加したりできます。

## 最初に設定する項目

正しい時間を計算するため、プレイヤー設定でVIPレベル、研究速度、建設速度を設定してください。

研究速度と建設速度は、ゲーム内で実際に使用する装備や一時的な速度アップを反映した値を入力します。Windows版でOCRを利用する場合は、ゲーム側とツール側で同じ研究分野を表示してから取り込んでください。

## OCRと安全性

- 画面取得は、利用者がボタンを押したときだけ実行します。
- ゲームプロセスへのアタッチ、メモリ読み取り、DLL注入、メモリ走査は行いません。
- ゲーム操作の自動化、キャプチャ画像の自動保存、外部送信は行いません。
- Windows標準OCRを優先し、利用可能な場合だけTesseractを補助的に使用します。
- OCRは誤認識する可能性があるため、反映された内容を確認してください。

## データとプライバシー

- Windows版の設定とプレイヤーデータは、ツールと同じフォルダー内へ保存されます。
- モバイル版のデータは、利用しているブラウザー内へ保存されます。
- 保存したデータを本ツールが自動的に外部へ送信することはありません。
- ゲーム画像、ゲーム内フォント、音声、クライアントから抽出した素材は同梱していません。
