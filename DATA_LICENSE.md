## Changes made to source material

Source information was normalized into project-specific JSON records. The
project adds stable identifiers, multilingual labels, prerequisite references,
level-by-level values, validation metadata, and planner-oriented layout data.
Names and values have also been corrected or cross-checked against the game UI
and the factual references listed below. Article prose, wiki images, videos,
game screenshots, game fonts, audio, and extracted game-client assets are not
redistributed.
