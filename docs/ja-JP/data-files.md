# 書き出し・読み込みファイル

[English](../en-US/data-files.md) | 日本語 | [翻訳ファイルの詳しい説明](translation-files.md)

RLMResearchPlannerが書き出すJSONは、種類によって読み込み時の動作が異なります。拡張子が同じでも用途は同じではありません。

## ファイルごとの違い

| 種類 | 含まれる主な内容 | 読み込み時の動作 |
|---|---|---|
| バックアップ | プレイヤー設定、所持資源、研究・施設レベル、登録タスク、課金候補 | 現在のプレイヤーデータ全体をバックアップ内容へ置き換えます。復元前に現在のバックアップを保存してください。 |
| 研究指示 | 名前を付けた研究タスク | 現在の設定やレベルを維持し、タスクだけを追加・更新します。完了済み研究は完了済みとして扱い、未達分だけを再計算します。 |
| 課金比較 | 課金候補、または比較ポイント設定 | プレイヤー設定や研究レベルを変更せず、課金比較へ取り込みます。同じ候補の重複は除外されます。 |
| 翻訳ファイル | UI文言、研究名、分野名、施設名、効果名、資源名 | 表示言語を追加または更新します。プレイヤーデータは変更しません。 |

## 操作場所

### Windows PC版

- バックアップ：プレイヤー設定タブ
- 研究指示：研究計画タブ
- 課金比較：課金タブの共有画面
- 翻訳：ヘルプタブ上部の「翻訳ファイル」

### モバイル版

- バックアップ、研究指示、翻訳：プレイヤータブ
- 課金比較：課金タブの共有画面

## 他の端末・利用者へ渡す

書き出したファイルは、メール、メッセージ、クラウドストレージなど任意の方法で共有できます。本ツールが自動送信することはありません。

バックアップにはゲームのログイン情報やパスワードは含まれませんが、研究状況、所持資源、課金候補などが含まれる場合があります。進行状況を共有したくない相手へは渡さないでください。

## 読み込めない場合

- ファイルの種類と選択した読み込み操作が一致しているか確認します。
- JSONを手作業で編集した場合は、UTF-8で保存されているか確認します。
- 古い版で書き出したファイルは、新しい版で読み込んでから再度書き出してください。
- 読み込み前の状態へ戻す必要がある場合に備え、先にバックアップを保存してください。
