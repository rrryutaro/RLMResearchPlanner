# RLMResearchPlanner モバイル版（PWA）

`RLMResearchPlanner` の手入力向けモバイル版です。ロードモバイルの研究レベル、施設レベル、プレイヤー条件、所持資源を端末内に保存し、目標研究や目標施設までの前提・時間・資源と、今すぐ開始できる研究の短時間順を確認できます。

## Version

`0.1.0 Alpha`

現在の`v0.1.0`はアルファ版です。主要機能を実際に利用できる段階ですが、機能・画面・収録データは引き続き検証と改善を行っています。

動作確認済みゲームバージョン: `v2.200.309`（必須バージョンではありません）

## 対応環境の目安

- iPhone / iPad: iOS / iPadOS 15.4以降のSafari。Safari以外からホーム画面へ追加する場合は16.4以降を推奨します。
- Android: Android 10以降と、最新版のChromeを推奨します。Androidのバージョンだけでなくブラウザーの更新状態も影響します。
- PC: 最新版のChromeまたはEdge、macOSではSafariも利用できます。

実機確認範囲が限られるため、上記は動作保証ではなく対応の目安です。古いOSや更新されていないブラウザーは対象外とし、不具合がある場合はまずブラウザーを最新版へ更新してください。

## バックアップを他の端末・利用者へ渡す

プレイヤータブの「書き出す」でJSONファイルを保存できます。保存したファイルは、端末のファイル管理アプリからメール、メッセージ、クラウドストレージなどで送信できます。受け取った側は、同じPWAのプレイヤータブで「読み込む」を選択します。

バックアップにはプレイヤー設定、所持資源、研究・施設レベル、登録した研究タスクが含まれます。ゲームのログイン情報やパスワードは含まれませんが、進行状況を共有したくない相手には送らないでください。

## 研究指示データを共有する

複数の目標研究を「登録タスク」へ追加し、プレイヤータブの「研究指示データ」から名前を付けてJSONファイルへ書き出せます。受け取った側が読み込むと研究タスクだけが追加・更新され、VIP、研究速度、所持資源、現在の研究・施設レベルは変更されません。

同じ研究が既に登録されている場合は高い方の目標レベルへまとめます。受け取った側ですでに目標レベルまで完了していれば「完了済み」となり、未達ならその人の現在レベルから必要な前提研究、時間、資源だけを再計算します。

## Scope

- 16分野・399研究・全3,385レベルの既存カタログを使用（詳細3,143、時間2,923、資源3,021レベル分）
- 研究カードから現在レベルを手動入力
- ツリー上でのピンチズーム・ドラッグ移動・全体表示
- 分野ごとの研究レベル一括入力
- 次レベルの研究時間、必要施設、資源、前提研究をカード詳細に表示
- VIP、研究速度、研究速度アップ、ギルドヘルプ、所持資源を手動入力
- 城または個別施設を選び、Lv.1～25の前提施設を遡って必要レベル・資材・建設時間を表示
- 建設速度、VIP無料時間、ギルドヘルプを適用した建設計画と、現在施設レベルの端末内保存
- アカデミーLv.25等の戦典・鋼鉄の手枷・霊魂石・ゴールドハンマーを集計し、所持数を差し引いたジェム目安を表示
- 施設ごとの完了操作で前提ステップを含めて反映
- 目標レベルまでの前提研究計画と合計時間・資源
- 前提研究を依存階層へ分け、下位階層をすべて先に完了できる順序と、研究ごとに収録した叡智の輪必要数・元時間33日3時間59分を通常研究の100%基準とする時間効率を表示
- モバイルの研究・建設ステップは2行表示とし、個別資材は必要なときだけ展開
- 目標研究の分野名は「必要な研究」の見出しへ集約し、各研究行では効果を省略せず表示
- 食糧、石材、木材、鉱石、ゴールド、古代の書物、月晶、マナ鉱石、特殊資材を集計
- 前提条件を満たす次レベルの短時間順
- 複数の登録タスクだけを共有し、受け取り側の進行状況を維持して不足分を再計算する研究指示データ
- デスクトップ版互換JSONバックアップの読み書き
- オフライン動作とホーム画面へのインストール
- 日本語・英語の研究名と研究分野名
- PC版と共通の英語基準翻訳JSONについて、ひな形の書き出し、読み込み、削除、未翻訳箇所の英語フォールバックに対応
- UI文言・研究名・分野名・施設名・効果名・資源名の利用者翻訳とRTL表示に対応（ツリー配置の左右関係は維持）

詳しいファイルの違いと翻訳方法は、[日本語ガイド](../RLMResearchPlanner/docs/ja-JP/data-files.md)または[English guide](../RLMResearchPlanner/docs/en-US/data-files.md)を参照してください。

モバイル版ではOCR、ゲームウィンドウ取得、プロセスアクセスを行いません。

課金タブは「入力」「保存一覧」「比較」に分かれ、保存一覧を最初から展開しません。目的別に候補を分類し、汎用・研究・訓練・建設・治療・融合・月晶工房の時短、ジェム、宝箱、資源、魔獣素材、戦闘、ブースト、建設用特殊資材、召喚獣、ヒーロー、アーティファクト、イベント、通貨、任意項目を手入力できます。

ゲーム内ショップで値を確認できる定型時短のジェム換算と、4個で上位品質1個へ融合する魔獣素材の品質ポイントを初期値として使用します。どちらも変更可能な比較基準で、ゲーム公式の現金価値ではありません。課金比較JSONだけを書き出して他者の候補を追加取り込みでき、プレイヤー設定や現在レベルは置き換えません。
公開元でレベル別数値を確認できていない箇所は、推測値を入れず「未収録」と表示します。

ギルドデュエルは研究項目の構造を収録していますが、レベル別の時間・資源・専用素材データは未収録です。

## Local preview

`index.html`を直接開くと、ブラウザーの制限により研究データを読み込めません。次のいずれかで起動してください。

- リポジトリ直下のランチャーで`RLMResearchPlannerPWA`の`PWA`ボタンを押す
- `StartRLMResearchPlannerPWA.bat`を実行する
- Node.js 18以降で次を実行する

```powershell
npm.cmd run serve
```

ローカル版は既定ブラウザーで`http://127.0.0.1:4173/`を開きます。ランチャーまたはBATから起動した場合、同時に開くコンソールを閉じるとローカルサーバーも終了します。

PWAのインストールとService Workerは、配信環境ではHTTPS（localhostを除く）が必要です。

## Data synchronization

デスクトップ版の研究カタログを更新した後は、リポジトリ内で次を実行します。

```powershell
npm.cmd run sync-data
```
