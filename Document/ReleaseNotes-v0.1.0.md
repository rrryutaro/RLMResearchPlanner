# v0.1.0 Alpha リリースノート

RLM Research Plannerを、Windows PC版とモバイル版を備えた最初の一般公開向けアルファ版として公開しました。主要機能を実際に利用できる段階ですが、機能・画面・収録データは引き続き検証と改善を行っています。

## 主な内容

- 16分野・399研究の研究ツリー、前提研究、時間、資源、パワーの計画
- 城Lv.25-5までと個別施設の建設計画
- 短時間で開始できる研究のページ切り替え付き一覧
- 研究・建設タスクの完了管理
- バックアップ、研究指示、課金比較、翻訳ファイルのPC/モバイル間共有
- Windows版の画面取得・日本語/英語OCR入力補助
- 課金候補の保存、目的別比較、ジェム・時短・素材の換算
- 所持スピードアップ、ジェム、登録済み課金を分けた研究・建設の充填シミュレーション
- 日本語・英語UIと利用者翻訳ファイル
- 固定研究IDを基準にしたPC/モバイル共通研究データセット
- 研究データと表示翻訳の分離、出典・確認日・検証状態の追跡
- JSON Schema、参照切れ、循環参照、レベル欠損、不正値の自動検査
- モバイル版のオフライン利用、ホーム画面追加、起動キャッシュ復旧
- Windows版のアプリ内更新とSHA-256検証

## 注意事項

- `v0.1.0`はアルファ版です。機能・画面・データ形式は今後変更される場合があります。
- 本ツールはIGGおよびゲーム運営とは関係のない非公式ツールです。
- OCRは入力補助機能であり、すべての環境・画面・研究項目を正しく認識できる段階ではありません。検証対象は日本語と英語です。ゲームとツールで同じ研究分野を表示し、結果を必ず確認してください。
- 公開元で確認できていない数値は推測で補完せず、未収録として表示します。
- ギルドデュエルは研究項目の構造を収録していますが、レベル別の時間・資源・専用素材データは未収録です。
- モバイル版のデータはブラウザー内に保存されるため、端末変更やブラウザーデータ削除の前にバックアップしてください。
- Windows版はコード署名されていないため、SmartScreenの警告が表示される場合があります。
