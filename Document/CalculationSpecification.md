# 計算仕様

## 研究速度

内部時間単位は秒。

```text
適用後秒数 = ベース秒数 / (1 + 研究速度% / 100)
```

端数方式は`ceiling`、`floor`、`nearest`を切り替え可能とし、現時点の画面表示は`ceiling`を使用する。ゲーム内の端数処理は未確認なので結果を推定値と表示する。

## ギルドヘルプ

初期候補仕様:

- 1回につき、その時点の残り時間の1%
- 1%が60秒未満なら60秒
- 残り時間を超えて減らさない
- ヘルプは1回ずつ順次適用

```text
repeat help_count times:
    reduction = max(remaining * 0.01, 60)
    remaining = max(0, remaining - reduction)
```

割合、最低秒数、端数方式は`GuildHelpPolicy`に分離する。

## 研究計画

目標研究から前提を深さ優先で探索し、現在レベルを満たす項目を除外する。同一研究・レベルは一度だけ出力する。循環を検出した場合は計画を中止してエラーにする。

各手順から以下を合計する。

- ベース時間
- 研究速度適用後時間
- ヘルプ適用後時間
- 資源
- パワー
- 古代の書物
- 未検証データ警告

さらにプレイヤー設定との差から次を算出する。

- ギルドヘルプによる短縮見込み
- ヘルプ後時間と所持時短の差
- 資源種別ごとの不足量
- アカデミーレベルおよび建物・その他条件の不足
- 通常開始、ギルド参加者が多い時間を推奨、ヘルプのみ、ヘルプ後に時短、古代の書物注意、資源不足、前提不足の開始判断
