# コミュニティ翻訳

[English](README.md) | 日本語

日本語と英語は、アプリと説明文書を公式に保守する言語です。利用者から提供された翻訳ファイルは、用語、画面表示、埋め込み項目、RTL表示を確認するまで、公式翻訳とは分けてコミュニティ翻訳として管理します。

## 翻訳を提供する

1. 現在のRLMResearchPlannerから英語基準の翻訳ひな形を書き出します。
2. [翻訳ファイルの説明](../../docs/ja-JP/translation-files.md)に従って編集します。
3. ファイル名は正規化したBCP 47言語コードにします。例：`fr-FR.json`、`ar.json`。
4. `author`と`license`を記入します。再利用条件が不明なファイルは、このリポジトリから再配布できません。
5. Windows PC版とモバイル版の両方へ読み込み、表示を確認します。

ゲームのスクリーンショット、ゲームから抽出した素材、ログイン情報、プレイヤーのバックアップデータは含めないでください。

## 対応段階

- **コミュニティ翻訳：** JSONを利用できますが、用語や説明文書が未完成の場合があります。
- **確認済み翻訳：** PC版とモバイル版で読み込め、埋め込み項目、主要画面、必要なRTL表示を確認しています。
- **公式保守言語：** アプリ文言と主要なGitHub説明をリリースに合わせて保守します。

コミュニティ言語の説明文書がない場合は英語を案内します。アプリ内で`text`が空欄の項目も英語で表示されます。
